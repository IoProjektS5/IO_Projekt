# Stos technologiczny

- Frontend: React
- Backend: FastAPI
- Baza danych: MySQL (MariaDB)

# Uzasadnienie wyboru stosu technologicznego

FastAPI to framework do tworzenia API w języku Python, który ma wydajność na poziomie Node.js i Go. Obsługuje standard OpenAPI, co ułatwi generowanie dokumentacji API. Zawiera komponent SQLModel (oparty na SQLAlchemy i Pydantic), który pozwala na łatwe mapowanie obiektowo-relacyjne (ORM) z bazą danych.
